# Mote Central 0.0.90 DEV

- 落地用户选择的第五轮三端共同风格：冷灰背景、白内容面、蓝色动作、系统字体、线性图标、稳定按钮边界与浅分隔。
- 将共同角色覆盖至模型、处理、来源、资料、设备和状态组件，保留成功、警告与错误的实际含义。
- 窄屏资料类型与设置导航更紧凑；随手记、完整原文、原任务返回和设置草稿保护保持可达。
- 设置只服务配置与维护，原有附件限制、处理范围、来源和时间继续明确显示。
- 修复英文会话有效期选项及窄屏 Memory 帮助、文件处理方案操作的截断或横向溢出。
- 补齐遗留配置表单的字段间距与执行按钮角色；窄屏问答保留完整模型名称，输入、附件和发送操作可滚动到达。
- 洞察报告支持完整 HTML 文档和无引文内容，保留作者样式及已有 iframe 安全边界；用量筛选的清除操作显示正确英文。
- 窄表单补充完整解析方式说明，文件时间使用完整秒数标签；Coding 接收回执和截图分组使用完整数量文案。
- 普通中央配置统一为私有 `mote.yaml`；文件编辑和设置页共用校验、全局 revision、原子保存及运行快照发布。旧 env、JSON 和 SQLite 运行设置不再作为配置来源。
- DEV 日志默认每份 100 MiB、3 份，结构化日志和监督日志分别轮转；显式容量保持原值，主动采用默认值后在正常重启时生效。
- 问一问移除估算的原文读取配额和自动容量砍半，完整授权依赖仍在模型调用前核对；录音原文去重并使用供应方创建或开始时间，Memory 暂时故障可在原范围和有效检查点内恢复。
- 中央启用多用户账号、会话和独立资料权限；管理员管理账号，资料、模型凭据、执行任务、连接器和对话按账号隔离。
- 普通原文修订保留历史回答并标记过期；明确删除、过期或撤回原件会清除依赖的历史私有产物，重启或相同 ID 的新资料不能恢复已删除内容。处理任务可返回保留的历史对话。
- 复用编译后的数据库校验语句，保留每次权限和当前数据核对，缩短多分支问答重试等待。
- 录音标题和时间更正产生正确的新修订；转写变短、为空或不支持解析时撤下旧语音的当前投影，保留历史原件、过期回答和成功的原音频备份。
- `node scripts/dev-server.mjs` 首次自动准备本地开发 profile；空账号库创建 `admin/admin`，已有账号和修改后的密码保持。

三端独立发布；中央源码包包含同版本 server/web。UI 检查见 [界面记录](../../../docs/validation/ui-rollout-2026-10-14.md)，多用户合流、回归与本地 Codex 实际调用结果见 [合流记录](../../../docs/validation/main-multiuser-integration-2026-10-17.md)。

本版使用 Wire 2、中央存储 epoch 5；旧单用户资料库、旧 owner token 和旧配置不自动迁移。跨代使用新空目录或独立 profile，并初始化账号；保留旧版本及其完整备份以便回退。正式部署自行设置强密码，开发脚本的默认账号仅用于本地开发。操作步骤见 [更新说明](../../../docs/updating.md)。

验证资料均为生成 fixture；实体设备、个人内容采集、外部供应商真实账号、真人审美与完整无障碍认证未执行。当前为手动部署的 DEV prerelease。
