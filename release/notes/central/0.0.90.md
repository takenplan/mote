# Mote Central 0.0.90 DEV

- 落地用户选择的第五轮三端共同风格：冷灰背景、白内容面、蓝色动作、系统字体、线性图标、稳定按钮边界与浅分隔。
- 将共同角色覆盖至模型、处理、来源、资料、设备和状态组件，保留成功、警告与错误的实际含义。
- 窄屏资料类型与设置导航更紧凑；随手记、完整原文、原任务返回和设置草稿保护保持可达。
- 设置只服务配置与维护，原有附件限制、处理范围、来源和时间继续明确显示。

三端独立发布；本条附件为 server/web 同版本的中央源码包。历史五轮候选和评分保留，新增实现与验证另见 [本轮记录](https://github.com/utopiafar/mote/blob/central-v0.0.90/docs/validation/ui-rollout-2026-10-14.md)。

验证仅使用生成资料、隔离中央与隐藏浏览器；物理设备、个人内容采集、真实账号或模型、真人审美与完整无障碍认证未执行。沿用已有 profile 的备份与手动部署流程，不清除配置、模型或资料。
