# Central 0.0.88 DEV

Sources and advanced settings are easier to discover through a source catalog
and purpose-based feature guide. Feishu and DingTalk recording setup is visible,
long status lists have collapsible details, and Coding Agent receipt, publication,
indexing and Memory status now appears inside Processing tasks. Published Coding
conversations remain in All materials. Existing links and authorization, processing,
retention and model defaults remain supported.

The release also fixes long Agent segment pagination, retained-run discovery,
same-page navigation, restored-value draft warnings and unavailable settings links.
English copy is synchronized with Android; only Central is released here.

Memory extraction and independent review share repeated context without truncating
original evidence. Work that still exceeds the existing host budget is split and
independently reviewed. New source projections separate literal body text from
metadata, preserve exact quote coordinates and retain older evidence versions.
Validation feedback reports safe field locations and actual candidate limits.
Independent review, complete coverage and owner-correction fences remain required.

Validation includes affected-component integration checks and Android debug unit
tests, plus generated-data browser checks of discovery, Coding status/body links,
long segment pages, English rendering and narrow layouts. The guided UI review
records conditional and unverified cases; it does not establish real vendor
account, physical capture or permission behavior.

Separate live-model validation of the Memory repair completed five selected
materials in seven independently reviewed batches. All 69 saved quotes matched
exact source offsets, including five multiline quotes. No owner-identity question,
host quote/structure/coverage correction or Mote task retry occurred. One Codex
stream interruption recovered automatically; the long recording still took about
19 minutes. This sample does not establish results for the entire historical archive.

See [UI journeys](https://github.com/utopiafar/mote/blob/central-v0.0.88/docs/testing-central-discovery.md)
and [Memory architecture](https://github.com/utopiafar/mote/blob/central-v0.0.88/docs/adr-memory-context-and-canonical-evidence.md).
This release does not automatically clear or reprocess a deployment's archive.
