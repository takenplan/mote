# Mote Desktop 0.0.89

- 来源同步逐条结清已确认的 ACK；后续断网不会抹去前面成功的进度。明确冲突或删除只隔离对应修订，临时拒绝和来源暂停保留待同步记录。
- 本地文件上传在会话过期、进程重启或 commit 回应丢失后继续恢复；已提交且中央规范原件仍在时取回 ACK，无需重传原始分片，保留原请求与修订身份。
- 中央内容、记录、Sessions 和成员列表直接使用服务端分页；无 OCR／预览文字的图片显示实际原件字节数。切换账号或失去权限后清除私有详情，并拒绝旧账号的迟到页面与原文响应。
- 减少大目录分批扫描中的重复遍历和本地文件检查点复制，保持原名称游标、扫描恢复、排除及错误处理。打包采集上传复用选中的图片读取与校验结果，减少重复载荷构造，保留队列顺序、逐条 ACK、失败记账与让出调度。
- 登录、连接、会话、权限、代理和传输失败显示对应恢复提示，避免把网络故障误报成密码或账号问题。
- 稳定标签改用 Prod 安装身份和常规诊断；Prod 保留系统凭据保护，独立 Dev App／明确的 dev Profile 使用私有文件凭据。原有账号、队列、草稿和授权隔离保持。

本次稳定标签为 `desktop-v0.0.89`，Prod Bundle ID 为 `dev.mote.collector`，App 名称为 `Mote Collector`。上次 `desktop-v0.0.88` 的 ZIP 是旧 Dev 身份 `dev.mote.collector.dev`／`Mote Collector Dev`；本次 Prod App 与它分别安装，不能把下载新 Prod 包理解为覆盖旧 Dev 或迁移其配置与队列。Dev 后续从 Actions 获取按提交标识的 Artifact。已有当前格式的同 Profile 更新应先退出对应 App，再覆盖该身份的 App；步骤见[更新说明](../../../docs/updating.md)和[Profile 决定](../../../docs/adr-profile-release-policy.md)。

附件按实际 CI 架构命名为 `mote-desktop-macos-<arch>-0.0.89.zip`，本次不承诺 universal 包。默认发布模式为 ad-hoc，未使用 Apple Developer ID 签名或公证；实际签名模式与架构以本次 CI 产物及运行报告为准。Prod 的运行、屏幕、日历及 Keychain 授权仍受 macOS 控制；本次未执行这些真实权限提示。

沿用 Wire 2、Ingress 3 和本机格式 4，与当前 Central 契约配套。没有新增旧格式兼容或自动迁移；旧 Dev 加密凭据不会自动转成文件凭据，先保存完整旧目录，再按更新说明显式建立新的 Dev 状态。发布 ZIP 不会安装 App、更新日常 profile 或部署中央，也不提供本次产物的签名在线更新。

验证范围：已有生成资料回归见[Desktop 记录](../../../docs/validation/desktop-parity-2026-10-18.md)和[性能记录](../../../docs/design/performance-round1-E-validation.md)。最终组合的检查、隐藏 Desktop／网页入口、原始失败与后继结果见[集成 PR #201](https://github.com/utopiafar/mote/pull/201)，历史分候选结果不能代替最终组合验收。发布构建、打包后 smoke 与安装包身份校验以 `desktop-v0.0.89` 对应的实际 Release CI 运行报告为准，报告链接在同一 PR 中汇总。实体设备／TCC、真实屏幕采集、睡眠锁屏、真实模型、Prod 权限、安装和部署未由这些生成资料回归验证。
