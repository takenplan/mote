# Mote Desktop 0.0.88 DEV

- 连接中央时使用多用户账号登录，凭据、待同步记录、草稿和后台响应受账号代际约束；切换账号后旧响应不能进入当前界面。
- 对话保留普通原文修订前的回答并显示过期提示；明确删除原件后显示删除状态，移除原文和引文操作。
- 处理任务的历史回答可返回保留的对话；沿用现有阅读、主题、连接和设置布局。

本版使用 Wire 2，与本次 Central 0.0.90 一起使用。旧 owner token 和不兼容的本机资料格式不自动迁移或重置；更新前保留旧版本与完整备份，按 [更新说明](../../../docs/updating.md) 配置新账号。

实际单元、原生构建和隐藏窗口生成资料检查见 [合流记录](../../../docs/validation/main-multiuser-integration-2026-10-17.md)。物理设备权限、个人屏幕采集及完整无障碍认证未执行。下载 DEV ZIP，退出 Mote 后覆盖 DEV App；当前为 ad-hoc 签名、手动安装的开发预发布。
