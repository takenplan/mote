# ADR：飞书文档作为持续上下文输入源

日期：2026-10-15。状态：所有者确认实施，验证结果另行记录。

导航适用范围：本文保留接入时的首页/内容术语；当前首屏和主要目的地以[展示 ADR](adr-ui-presentation-packs.md)为准。新增第五个接入动作不恢复旧 Home 首屏，也不增加飞书主导航。

## 用户旅程与决定

飞书文档与文件、截图、录音是同级输入源。所有者连接一次，明确授权发现范围后，中央持续收集相关文档的正文版本及提供方能证明的活动线索。文档在现有资料库阅读，模型通过既有只读证据、Memory 和问答使用这些资料，不增加飞书专属主导航。

沿用三端既有来源目录和原生「首页 / 内容 / 问一问」结构。Mac 与 Android 的首页和添加选择器新增「连接飞书文档」第五个动作，分别打开中央 Web 和原生中央配置；这取代 [行动优先 ADR](adr-client-action-first.md) 中首页固定四个动作的数量，保留其导航与任务职责。

已确认的六项决定：

1. 自动发现“我创建的、我编辑过的、平台打开筛选命中的”文档；不默认扩展为所有可访问资料。提供方打开信号包含 API 自采集污染的未知风险，只能显示为提供方线索。
2. 活动发现的文档在后续活动触达时保存当前正文；明确选择的文档、文件夹和知识库分支持续检查。明确的文档排除规则先于收集。
3. 首次默认回看最近 30 天涉及的文档，取得当前可读版本，不恢复或承诺全部历史编辑版本。之后保存实际观察到的修订。
4. 保存正文与普通文本表格；图片、附件、嵌入电子表格和多维表格只保留引用。规范 Markdown 正文是授权的正文表示，不因此取得嵌入二进制资源的下载授权。
5. 默认中央每 15 分钟检查，支持手动立即检查。上游索引延迟、中央关闭和实际失败均可能造成缺口，不承诺准点或逐次行为日志。
6. 继续使用 Mote 专用官方 CLI 配置及用户身份只读授权；文档与日历能力分别判断所需权限。专用配置不等于独立操作系统钥匙串。

保存范围、元信息预览、开始正文同步分别执行。预览不读取正文、不发布文档或活动输入，也不触发 Memory。第一次开始同步是对当前预览范围的明确确认；更改范围需要重新确认。后续正常周期读取不需要逐篇确认。暂停、取消选择、断开保留已有归档；彻底删除沿用既有 owner 删除入口。重新授权和保存说明不恢复用户暂停的来源。

## 内容与活动证据

稳定上游文档 ID 标识正文。Wiki 与普通链接、文件夹和显式选择形成成员关系，不因入口改变产生新资料。正文不变保持幂等；A→B→A 保留新的观察版本。文件名、标题、第一人称和账号访问权不能证明整篇正文由所有者撰写。

文档活动是独立的 `kind=event` 来源条目，使用版本化 `document.activity`：提供方、文档 ID、账号指纹、原生动作、证据依据、时间精度与范围、实际观察时间及限制。搜索谓词命中不是逐次事件；重叠查询不制造重复人类动作。只有上游给出可靠的精确发生时间才填写该时间，当前搜索路径保留范围及未知精度。

正文版本和活动观察分别去重。再次接触未变化的文档不重做整篇正文处理；他人改了文档不证明所有者编辑。读取当前正文不证明那就是之前打开时所见的版本。正文失败时已核验的活动线索仍可归档，正文失败单独重试；活动获取失败不伪造空的完整历史。

当前严格日范围工具按证据的真实时间锚点筛选。只有范围、没有准确发生日期的历史活动，以实际取得线索的观察时间归档，保留提供方范围供模型解释；不能据此完整恢复某一天的每次活动。没有实际测量就不产生阅读时长。

## 责任与持久恢复

连接器负责固定只读操作、权限、分页、固定绝对时间窗口、范围成员和持久检查点。发现元信息、读取正文和发布前均核对账号、来源状态与范围版本。逐篇失败不阻止其他文档，重启恢复未完成的发现页与待处理文档。用户输入不能变成 shell、任意 API 或网络抓取工具。

正文继续进入普通 source-item Material 与个人策略。可信的活动投影提供 `daily-events` 命名输入，活动只使用日常事件策略，正文不重复进入该策略。独立的飞书默认组合初始化时复制当前普通组合并追加日常事件，之后保留所有者设置和来源覆盖，不为历史输入补发模型授权。

模型解释日记叙述者、会议责任、第三方观点、计划状态和个人价值；宿主只验证范围、版本、引用与授权。原文、观察和精选分别保留。现有长期整合只消费精选 Memory；普通活动之间的关系可由 Ask 或洞察结合原文分析。用户不需要逐条批准已通过独立审核的 Memory，纠正与删除沿用既有入口。

## 取代检查

| 类别 | 处理 |
| --- | --- |
| KEEP | 中央执行、官方固定版本 CLI、专用配置、只读查询、稳定原件与不可变修订、未知默认归属、现有个人策略和独立审核、来源说明与隐私删除、断开保留历史。 |
| CHANGE | 显式链接扩展为活动发现与固定范围；元信息预览和首次开始分离；逐文档持久状态、失败隔离及恢复；文档与日历权限按能力判断；云活动提供可信日常事件输入。 |
| REMOVE | 新文档范围的固定 30 篇限制、文档隐藏在 Android 日历选择中、正文去重吞掉活动、首篇失败终止所有文档、保存或重新授权恢复手动暂停、把打开谓词当成人类完整阅读。 |
| EXCEPTION | 已保存且没有发现配置的旧选择继续只读取明确链接；旧来源覆盖及已授权固定配方不改；历史模型工作需要显式范围，不因安装或重启重跑。 |
| UNKNOWN | 真实租户权限、上游索引完整性与延迟、官方 CLI 自读是否推进打开筛选、跨组织可见性和系统钥匙串行为；生成响应和模型语义测试不能代替真实飞书验收。 |

原先文档/日历共用的语义在本文标记的范围内由本决定取代；录音专用 Provider 不在本次身份迁移范围。相关说明见 [飞书接入](lark-integration.md)、[Memory 分层](memory-admission.md)、[日常事件](adr-daily-event-memory.md)、[来源说明](adr-file-source-context.md) 和 [验收场景](testing-feishu-document-context.md)。
