## Delivered production behavior

The real `buildApp` composition installs the adapted existing PluginCenter shared
catalog, user ConfigService domain, Cordis/FeatureRegistry worker host and M05
task registration. It restores administrator release resolution/installation,
private instance configuration/check/enable/pause/stop, fixed task/history
snapshots, scoped task invocation and event subscriptions. It adds no second
executor, global private Store or default owner. Installation gives no historical
authorization. Unsupported domain adapters and native provider recipes remain
explicitly unavailable until their owning modules register them.

The [design and downstream contracts](../design/multiuser-plugins.md) describe
M03's fixed source capability, M06's processing adapter, M07's exact namespace
and host runtime factory, M04 fixed model admission and M16 lifecycle coverage.
Native factory acceptance uses a synthetic provider on the real fixed-release
recipe path; it does not claim real multi-user Mem0/Hindsight acceptance.

## Isolation and lifecycle matrix

| Journey | Observed acceptance |
| --- | --- |
| New package/component registration | Actual ZIP, manifest/digest verification, child callback and Cordis FeatureRegistry registration; no central business dispatch addition. |
| A/B identical instance IDs and source IDs | Different configuration/results/events; package view and A export contain no B instance data. Ordinary users cannot resolve/install/uninstall code; admin cannot read B's snapshot. |
| Source capability | Generated plugin calls the actual production M03 binder and real M02 transactions. Capture/source intake, paging, byte-range read and canonical publication succeed. Existing same-user ungranted originals, cross-source/transitive Material dependencies, forged selectors and B's originals are rejected without publication. Restricted device credentials cannot reach plugin control/invocation. |
| Pause/drain/stop | Pause permits prior work to drain; stop rejects delayed RPC/event/result publication. B continues with its own instance and fixed data. |
| Release/config/history | Identical ZIP bytes under different fixed release metadata retain distinct package IDs. Old tasks/configuration and exact owner/binding history survive restart; other bindings have no records. |
| Model extension | Real M04/M05 original model snapshot remains fixed across selection change; no B settings or reusable key enters output. Typed transient host failures retry three times with the same model snapshot despite plugin attempts to conceal errors. |
| Callback completion | A fire-and-forget host callback must settle before task success. A failed host operation cannot become a successful result. |
| Revocation/deletion | Grant narrowing, account disable and delete reject late callbacks and subscriptions. Running A is fenced before worker closure; B remains usable. |
| Probe erasure race | A generated worker delays initialization, then attempts to recreate its cwd. Delete joins it before local removal; the directory remains absent after the delayed-write interval. |
| Probe/live storage | A new check uses disposable staging and cannot overwrite live retained records for the same configuration. |
| Shutdown | A real loopback HTTP check waits forever in initialization; preClose retires its worker before socket drain. Shutdown completes and the check cannot report success. |
| Runtime generation | Another SQLite connection advances the persistent fence; the host reopens a new process instead of reusing the old PID. |
| Retirement and uninstall | An owner can repeatedly release a stopped receipt; B cannot release it. Removing the definition and releasing references permits package uninstall. |
| Domain disposal | A model-domain registration disposes its M05 handler idempotently and can be registered again without a partial handler conflict. |
| Native host recipe seam | Fixed Mem0 recipe installation plus a registered synthetic host runtime yields separate A/B histories and immutable owner namespaces without changing central dispatch. |
| Export/restore | Export omits credential references, B and active grants. Real separate M04/M09 lifecycle hooks restore disabled, unchecked definitions with empty source/capability/history grants. Wrong envelopes fail before publication. |
| Instance administration | Deleting an administrator's private plugin domain does not revoke its still-authorized shared catalog administration. |
| Offline vault relocation | After closing and copying the generated vault and removing the original directory, package loading uses the current cache. A/B exact retained records remain separate, B gets 404 for A history, and the original fixed task still completes through authenticated APIs. |
| Actual late source RPC | Generated code waits on files in its own worker cwd. After ingress deletion/account disable it attempts the actual bound RPC and receives rejection; after stop/grant narrowing/plugin deletion its process is retired before it can call. No late source head, task result or subscription event appears, while B continues. Pause separately drains already-admitted source work. |

  runtime map. A generated plugin recreated its directory after delete returned

  true`. The fix tracks every worker from construction and joins all of the

  opening a newer generation waits for old handles to retire. A separate SQLite

  incomplete model-handler disposal, lost typed host errors, unjoined host RPC
