# 用户反馈后的 UI 续迭代验证

本轮承接用户对离线 HTML 的实际反馈：部分图只有加载画面，中央 Web 设置混有新记录动作，Android 视觉角色不统一。保留原五项量表，追加页面职责与任务聚焦、视觉一致性与平台适配，合同见 [设计范围](../design/ui-focus-and-consistency-2026-10-13.md)。这是生成资料、后台运行界面的验证；物理设备、个人屏幕、真实模型、外部账号和真人理解没有据此获得验证。

## 已确认的失败与处理

七张旧 Web 参照图显示 Suspense 加载壳。旧检查只证明 PNG 可解码、标题和路由存在，不能证明目标业务页完成加载。本轮等待精确目标路由、消费者标记、挂起 API 响应归零，以及可见忙碌状态消失，再记录完成内容、真实空状态或明确限制。慢笔记响应故意延迟 900 ms，实际等待 1510 ms 后才截图；存储 503 作为显式限制场景单列。七张旧图仍保留原字节和 SHA，比较区排除并显示原因，不能倒填为旧轮次已通过。

旧 Android 原文和目录有八张局部对话框图，缺少实际父页与遮罩。本轮通过应用自身完整窗口及同进程实际弹窗 View、实际位置和 dimAmount 绘制，保留 `FLAG_SECURE`，没有使用设备截图或拼造父页。历史局部图明确标为片段，不作为完整手机页面比较。

Web 设置族隐藏全局随手记，未登录设置保留身份验证与配置语境；普通模型设置不再虚构一个默认提问返回任务。功能目录保留 16 组 / 78 项，移到首页的次级职责，移除“开始一件事”面板，旧 `#/guide` 和浏览器返回仍可用。真实带入的 `returnTo`、笔记草稿、配置测试及存储维护保留。新的内容等待也暴露并修复了 320 px 文件输入导致的横向溢出。

Mac 设置族隐藏通用添加主动作，内容与首页仍可保存四类资料；保留设置草稿确认与原生菜单。Android 第一轮统一表面、动作、表单、阅读和底栏角色，第二轮根据独立复评把旧设置仪表盘的采集和同步操作移到既有首页区域。设置直接显示配置与维护；整体采集与屏幕 / 应用活动分别标明范围，原权限预览、明确开始及保存配置不自动开始的行为保留。普通笔记等原文父页使用实际来源标题，只对截图生效的分组 / 缩略图控件在其他来源隐藏，切回截图保留选择。笔记当天为空说明选择日期或添加笔记，不要求采集授权。查询与筛选范围不变。

Android 旧“关闭详情自动回首页”的证据不足：只检查 Home 标签并直接结束 reader Activity 无法证明用户路径。本轮验证实际关闭对话框 → 匹配来源 / 日期的记录页 → 实际原生返回 → 同一记录的原首页，未改变返回政策。

## 生成资料与验证结果

Web 最终生产构建、类型检查及 360 项 Web 测试通过。真实浏览器导航 fixture 通过。最终界面矩阵为中英文、1440 / 820 / 390 / 320 px，另有英文 200% 浏览器缩放：153 张原始截图、41 条旅程通过；142 张明确选择用于离线评审，标签无重复。200% 的 CSS 视口为 720 × 484、DPR 4，实际 PNG 为 2880 × 1936，不标成普通 1440 px 图。每张图核对 SHA 和目标内容就绪状态，早期重复截图保留为原始旅程证据。第二轮还修复了独立评估者发现的真实 Ask / Insights / Import 配置入口丢失原任务的问题，沿用已有配置链接并携带实际当前路由；真实 Ask 提示 → 模型连接 → 模块 → 原 Ask，以及洞察和真实生成 TXT 导入的配置返回均通过。直接访问设置仍不虚构返回任务。

Mac 完整构建与隐藏的 Electron UI fixture 通过，包括设置族无添加、设置草稿离开确认、笔记保存和原文、内容分页、最小窗口及恢复失败。重跑曾暴露 fixture 临时注入的已登录状态与实际离线状态回调竞争；测试期间统一两个合成状态通道后完整重跑通过，没有为此修改产品授权或登录行为，失败日志保留。当前 44 张截图使用与构建 SHA 绑定的独立生成配置，覆盖中英文、1140 × 808 / 820 × 620。Mac 离线功能目录入口实际进入连接设置并显示限制；这不证明已打开完整中央目录，完整目录内容使用 Web 场景。

Android 最终 Development 应用 / 测试 APK 构建与 313 项 Development JVM 测试通过。唯一候选 APK SHA-256 为 `03275d394e64a8b1c7e48f04c521a8b8a910f231f66bb5a04cf14e7deb7377b4`，源对应 `834b7a18`。四条件各 3 项共 12 项通过，导航 8 项通过 / 2 项可选中央实连跳过，范围与设置 5 项通过，阻塞队列下从真实 Home 点击 Start 的响应专项 1 项通过。该专项仅模拟可用性且没有采集 service instance，不证明实际采集。86 张最终整窗图、sidecar、PNG 尺寸 / SHA 与窗口边界核验通过，较早 R10 构建存于 `before-*`，不作为最终候选。

受影响组件与消费者最终使用 `npm run check:affected` 通过；共享翻译改动按仓库规则选择全部三端，包含全量 TypeScript 集成、8161 条中英文及 TS / Kotlin 调用检查、313 项 Debug JVM 测试。最终代码已在本任务本地 `codex/ui-continuation` 分支的 `834b7a18` 提交；这不代表已进入 main 或已发布。独立评估者不修改产品，实际操作当前生成 Web、Mac 与专用无窗口 Android 模拟器，再审图评分；最终七项分数与接受理由见 [独立评价](../design/ui-feedback-evaluator-2026-10-13.md)。

## 离线交付

交付仍位于 `.mote/ui-review-2026-10-13/index.html`，ZIP 包含本地脚本、PNG 和白名单报告。反馈前来源来自已冻结的原交付：Web 原参照、Mac D2 / Android R8 原候选；保留原始字节、旧评分和来源轮次。新增两项当时未评估，历史分数不冒充当前复评。

当前方案均重新生成，要求明确的目标内容就绪状态及图像哈希。缺少的场景、语言或条件明确显示缺项，不能拿其他图补齐。三端倾向与备注只保存在浏览器本地，使用本轮独立的存储键；导出不发往服务器。实际后台 `file://` 页面已通过 373 张原始 PNG、18 个平台 / 语言 / 条件的全部可选场景检查，外部请求为零。三端选择、语言 / 条件 / 场景、缺项与失效旧图原因、备注保存和导出、放大 / Escape、宽窄布局及损坏冻结输入拒绝均通过。373 张中当前候选为 258 张（Web142 / Mac44 / Android72），反馈前 115 张保留历史来源；其中七张失效加载图只留原始字节，不在完成页面对照中展示。ZIP 白名单 393 个文件打包并逐图复核通过；移动到新的解压目录后，实际 `file://` 页面再次通过同样 373 张图 / 18 个条件的交互检查。七项评分完整呈现、旧加载壳排除及反馈前参照不能从旧目录重新推测的 CLI 拒绝回归均通过。最后只更新报告正文，保留相同 HTML / JS / PNG 并再次静态复核文档链接和字节后重新打包。
