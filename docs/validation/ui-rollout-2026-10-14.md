# 第五轮三端 UI 全面落地验证

2026-10-14。所有者选择第五轮，并要求每个页面实际视觉验收；规则见 [落地方案](../design/ui-rollout-2026-10-14.md)。五轮历史图片、评分和 producer 保留，本篇记录本次实现与实际验证。

当前仍在逐页复核，不能作为三端验收完成或已发布的声明。

## 页面与视觉门槛

每个内置页面、二级配置、详情、弹窗与重要状态关联内容就绪原图。实际打开可读原图，核对冷灰／白／蓝角色、系统字体、线性图标、控件边界、分隔及页面职责，并核对完整原文、限制、来源、时间、状态和返回位置。长页中部、末端、展开区和内部滚动须有图；中英文、常规和窄屏覆盖，重点补充真实缩放、大字号、焦点与输入法。

测试、图片哈希、DOM 和几何断言支持身份、行为与边界验证，不能代替视觉检查。失败尝试和旧截图不计入最终通过；相同图片只能明确映射到已实际看过的原图。缺图、未看或未解决问题均阻止验收、合并和发布。

## 验证边界

仅使用生成资料、临时 profile、隔离中央、隐藏浏览器／Electron 和专用无窗口 Android 模拟器。Android 保留 `FLAG_SECURE`，取证范围限定于应用自有 View／Canvas 与专用测试中的自有 Window 像素；系统合成屏幕、系统键盘像素、个人截图与真实采集不包含。系统权限／选择器、版本元数据和外部插件 API 的 fixture 适配边界分别记录。

早期关于 Android 多个页面底栏图标缺失的判断已撤回：实际查看原图的无损像素区域后，底栏图标和文字完整。原图、裁剪矩形与 SHA-256、早期判断及纠正均保留；裁剪只用于检查原像素，不能替代真实画面或合成通过证据。指南的两处实际原像素缺口单独记录，不能据此扩大为一般产品渲染故障。

未执行物理设备、真实权限与个人采集、真实账号或模型、真人审美研究和完整无障碍认证。生成场景通过不推断这些范围。DEV 构建、签名、身份、发布附件及目标提交须另行核验。
