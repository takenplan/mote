## Contract and regression

The generated Server regression commits an ordinary archive, verifies the live
receipt unchanged, expires its transport by 25 hours, invokes public ingress GC,
and restarts the real app. A new public begin must return the same business ACK
and original ref/hash/bytes with `duplicate:true` and no parts, active upload row
or new part/commit authority. A keeps one capture; equal-identity B keeps zero
and cannot read A's locator. A resync with another batch still has one canonical
capture. Authenticated original download must equal the generated bytes.

It also checks conflicting path/size/hash/MIME rejection, source withdrawal,
logout, a fresh authenticated account epoch without any intake notification,
and removal without a new canonical ACK. Existing snapshot recovery and expired
uncommitted transport scenarios remain distinct. Desktop's real
`LocalSourceManager` consumer is owned by the original Desktop writer; no Desktop
file is edited here.

## Supersession

- KEEP: current Wire2/Ingress3, source/device/owner/epoch gates; immutable current
  canonical revision and byte identity; one-day staging GC; old part/recovery
  revocation, deletion/forgetting, snapshot expiry, physical uncertainty holds;
  normal processing/Memory/Ask admission and explicit retry rules.
- CHANGE: when no transport row survives, an ordinary available archive can
  supply a read-only canonical ACK through M02's host read port and M03's owned
  original reader. An ephemeral upload UUID is not the durable business identity.
- REMOVE: reliance on a retained expired upload row or its private UUID to prove
  that a committed original was received; mandatory retransmission solely because
  staging GC discarded the ACK.
- EXCEPTION: explicit processing-profile/import-declaration requests are outside
  this fast path. Their full override manifest is not canonical capture data, so
  all existing processing intent/admission semantics remain unchanged. Snapshot
  or reference input is not converted into a durable archive capability.
- UNKNOWN: all new runtime outcomes; independent Root review and actual Desktop
  red/green; final aggregate composition and whole-PR checks; broader override
  canonical ACK parity. No such check is inferred from older File fixtures.
