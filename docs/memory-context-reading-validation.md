# Memory 原件上下文读取验证

本文件对应[上下文读取 ADR](adr-memory-context-reading.md)。每项需区分生成 fixture 的权限/生命周期结论、真实模型的语义审读和未执行项目；不能用 stub 输出宣称身份或日期判断正确。

## 用户旅程与回归矩阵

| 场景 | 必须观察的行为 | 证据级别 |
| --- | --- | --- |
| 导入本人日记后形成 Memory | 冻结说明进入正式 Material、目标成员与实际提取/审核输入；正文支持的主叙述者可以对应本人，少量通话声明不机械否定日记 | 生成入口＋单独真实模型审读 |
| 长日记容量拆分 | 末级目标可主动读取同一已授权原件的回顾开头和动作续文；兄弟目标覆盖不被重复提交；上下文不生成独立候选 | 生成入口、范围与保存引文 |
| 不同年份的录制与回顾 | 明确回顾年可支持事件年份；录制年、导入年和执行时间不代替事件年份；年份有依据而月日含混时保留月日缺口 | 实际输入检查＋真实模型审读 |
| 跨年、更正与照片回顾进度 | 不把开头年份无条件套到跨年例外；进度日期不成为此前所有事件日期 | 生成语义样本＋真实模型审读 |
| 动作在边界被截断 | 读取续文后只保留它实际支持的动作与结果；猜测、计划和未知后续不能改成确定完成 | 生成语义样本＋真实模型审读 |
| 主日记、通话、引述和背景声音混合 | 日记本人对应不传给每个声音；本人的表达、他人转述与角色不明部分分别限定 | 生成语义样本＋真实模型审读 |
| 相同标签、不同原件或声明 | 不把另一篇日记、批次共同声明或 local speaker ID 当作本片段的身份依据 | 生成传输＋真实模型审读 |
| 提取读取过上下文、审核仍有缺口 | 审核能独立读取许可范围，完整草稿保留；它不以提取结论为批准条件 | 生成独立审核入口 |
| 另一原件实际补读后被删除 | 提取读过的精确原句重新披露给审核；保存前登记依赖，删除后清除含该原件的私有草稿及依赖 Memory，其他独立目标保留 | 生成跨原件读取/删除入口 |
| 另一原件只有许可、尚未读取时更正或删除 | 目录不授予引用资格，未读许可不成为本批依赖；当前目标提取、审核和发布仍可完成 | 生成未读许可状态转换 |
| 未授权、删除、更正、版本变化或撤权 | 上下文读取和迟到发布被拒绝；不得借声明、目录、候选或派生产物增加权限 | 生成权限与状态转换 |
| 工具或输入预算不足 | 保留具体未解决范围，既不宣称材料不存在也不循环读取相同证据；不用新次数或固定窗口掩盖缺口 | 生成预算边界 |
| 旧任务、成功兄弟与重启 | 无 `contextReadVersion` 的任务保留旧边界；新任务的读取版本和范围恢复；成功范围不重放 | 生成真实启动/恢复入口 |
| 默认升级 | 内置普通/采集 v3 默认升级未来选择，旧 v2/v3 授权资格保留；来源覆盖、自定义组合及后来选回旧版不变，不生成历史授权 | 生成设置与重启测试 |

## 隔离对照

无模型的输入对照固定同一生成原件、声明、目标、时间与模型配置，比较局部目标、目标＋开头/续文及按需读取路径。保存宿主读目录、模型实际输入、工具请求/结果和引用资格；确认主体/年份原句在缺失臂不可读、在相应许可臂能精确读取。

真实模型对照分别改变上下文可读性和个人策略版本，保持其他条件不变。审核对照固定同一完整草稿，避免把生成差异误归因于审核提示。将正确保守、本人归属不足、错误本人归属、事件年份、精确月日、计划/完成和转写歧义分项审读，不用关键词命中给出通过结论。
