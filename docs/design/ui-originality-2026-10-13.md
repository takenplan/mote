# 原生原创性续迭代与独立 HTML 展示

用户在五轮迭代之后要求 Mac、Android 的 Originality 严格超过 7，其他四项不下降，继续后台测试；确认“解耦”指独立打开、无需后端和设备权限的 HTML 预览。

## 固定合同

沿用 [五轮独立评估](ui-iteration-evaluator-2026-10-13.md) 的指标、尺度、锚点和真实操作 / 截图反馈方法。Mac 与 Android 的接受门槛为 Design quality ≥8、Originality >7、Craft ≥8.5、Functionality ≥8.5、第一眼理解与重要能力可发现性 ≥8.5。Web 保留已验证的第 5 轮实现。每个候选必须由独立评估者判断，不能为达到目标改动尺度或掩盖缺口。

## 产品边界与视觉方向

最接近的现有模式是 Slate 配色、行动优先四个入口，以及 Home / Content 共用的资料列表和原文阅读。第 5 轮的首页由多个分开的卡片与横条组成，独立评估指出它仍像通用仪表盘。这次以档案页的连续版式连接添加、资料和出处，以真实资料层级而非虚构内容形成产品身份；这是视觉呈现的调整，不重写系统责任。

- **KEEP**：三个原生主目的地、四个平等动作、草稿 / 返回 / 生命周期、既有内容和状态 API、真实原件与处理边界、全部功能入口、权限和安全窗口。
- **CHANGE**：首页的连续资料页构图、添加面板与列表 / 阅读的视觉关联、字体层级、实际来源和时间的呈现。
- **CHANGE（复查修正）**：Android 首页“最近内容”显式使用本机内容页已有的全部来源读取方式，包含已经保存的随手记；原先隐含的屏幕来源默认值会错误显示空内容。保留查询上限、文件排列、采集 / 权限 / 发送规则，其他屏幕浏览调用保持原默认值。
- **REMOVE**：重复卡片外框、无助于资料身份的装饰性胶囊和竞争性的版面切割。
- **EXCEPTION**：Android 使用原生字体与触控控件，Mac 保留桌面键盘及窗口适配；Web 保留原实现。
- **UNKNOWN**：真实新用户理解速度、物理设备和真实模型效果，继续单独报告。

## 展示边界

HTML 展示从已执行的生成 fixture 复制图像，以平台、状态、尺寸和轮次切换，支持并排比较和静态旅程浏览。展示控件只浏览证据，不连接后端或设备，不模拟真实保存或授权成功。原生截图保留像素真实性；尚未拿到的画面和评分明确标注。用户可以据此选择是否接受视觉方向。

本轮的独立反馈另记在 [续迭代评估](ui-originality-evaluator-2026-10-13.md)，不改写前五轮历史。

最终交付选择 Mac D2、Android R8，两端 Originality 均为 7.5；Mac Design quality 8.5，Android 8；两端 Craft、Functionality、追加项均为 8.5，其他指标不下降。当前分支 `codex/ui-continuation` 承接原五轮与续迭代，并保留基线中的更新版说话人显示修复。

Android R6 的首页断言误匹配隐藏 Content 页，相关已有内容首页证据作废；R7 已修正显式全部来源查询并获独立接受。这次用新构建重跑发现英文 320 dp / 130% 字体下第四个动作裁切 23 px，动作行上下内边距由 8 改为 6 dp，字号、完整文案、64 dp 最小高度和四动作不变。四条件全部重跑后接受 R8。

Mac D 的英文后台操作标签在切语言后仍缓存中文；D2 保留 authored key，在读取状态时按当前语言翻译标签与完成 / 失败后缀，单元与真实切语言保存笔记回归通过。实现者与当前复评者分开，复评保持固定标准，详见 [续迭代评估](ui-originality-evaluator-2026-10-13.md)。

历史临时来源已清理，离线生成器通过冻结 manifest 的 PNG 哈希保留第 5 轮证据；当前双端明确刷新候选，删除旧候选场景，不用旧画面补缺项。报告链接与图片均随包携带。执行范围、失败历史、独立操作与未验证项见 [续迭代验证](../validation/ui-originality-2026-10-13.md)。
