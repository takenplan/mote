# 三端 UI 五轮迭代

## 方法与目标

沿用 [Anthropic 的前端生成与独立评估方法](https://www.anthropic.com/engineering/harness-design-long-running-apps)：实现者与评估者分开；每轮先约定可验证的范围，再操作真实运行的界面、检查截图、记录具体问题，把反馈用于下一轮。保留 Design quality、Originality、Craft、Functionality 四项，继续强调设计质量与原创性。追加第五项：初次到访能理解 Mote 的用途，重要能力有可发现的入口。第五项不取代原指标。

评估使用固定尺度与同一组生成资料场景。评分是独立模型的设计判断，不是用户实验结果；自动化通过也不能证明真实用户第一眼理解。每轮根据问题决定沿当前方向细化或调整方向，最终选择综合表现较好的实现，不能因为它是最后一轮就默认最好。

## 范围与保留边界

用户确认 Web、Mac、Android 三端一起迭代。参考既有 Slate token、行动优先导航、资料列表与详情、功能目录，不引入新的采集、处理或隐私策略。

- **KEEP**：Web 五个主目的地；原生首页、内容、问一问；原生四个平等动作；功能和设置路由、草稿、返回行为、真实同步和处理状态、权限与原件边界。
- **CHANGE**：用途说明、视觉层级、首屏空间分配、已有重要功能的入口表达、窄屏和键盘可用性。
- **REMOVE**：由评估确认的重复宣传和竞争性的入口表达；不删除其承接的能力或旧路由。
- **EXCEPTION**：Web、Mac、Android 的平台差异继续保留；采集与授权仍在设备本机进行。
- **UNKNOWN**：未经真实用户实验的理解速度、未经实机验证的系统权限与后台行为、真实模型效果。不得以 fixture 或编译通过替代。

架构和产品事实以 [客户端导航](../client-navigation.md)、[Slate 基线](../ui-slate.md)、[行动优先 ADR](../adr-client-action-first.md) 为准。本轮是现有界面的迭代，不改变上述架构责任。

## 场景与证据

基线和每轮使用隔离的 Central、Electron renderer 和原生生成资料界面；覆盖未登录、首次空库、已有资料、未配模型、窄屏、中英文、键盘或系统大字体。所有截图仅包含合成资料，不读取个人屏幕或启动真实采集。入口检查包含添加资料、内容阅读、问答、记忆、洞察、来源、后台进度和设置；端侧只列其已有能力。

具体评分与逐轮操作记录见 [独立评估](ui-iteration-evaluator-2026-10-13.md)，能力入口与测试分工见 [旅程清单](ui-iteration-journeys-2026-10-13.md)。首轮原生独立操作缺少完整证据，评估文件明确记为未验证，不能用实现者的自动化通过代替。

用户追加要求后，所有测试和独立评估均保持后台：Web 使用隐藏 renderer / 浏览器，Mac fixture 禁止显示或聚焦测试窗口及启动外部浏览器，Android 使用独立无窗口模拟器。生产的窗口和浏览器行为不因测试约束改变。

## 轮次记录

| 轮次 | 合同与实现 | 独立评估与下一轮输入 |
| --- | --- | --- |
| 基线 | 当前构建，空库、已有资料、未登录、窄屏与独立原生操作 | 重复的入口和大白卡片削弱层级；Android 离线资料库误用问答提示。 |
| 1 | Web 合并档案介绍和找回工具，删除重复问答 / 设备宣传；原生补清本机保存、中央整理和提问关系 | 用途更清楚，但原生仍过于通用；Web 手机上的竖排工具推迟添加入口，单张笔记卡被拉宽。 |
| 2 | 原生四个平等入口改成紧凑记录框；Web 手机工具横排、首次导入和完整功能入口前置、最近记录改列表；Android 离线提示按页面区分 | Web 可发现性改善；独立操作发现 Mac 未连接时提问露出 IPC 错误；功能目录分类位于模型说明之后，跳转不移动焦点。 |
| 3 | 修复 Mac 离线提问和中央入口目标；原生完整功能路径清晰说明支持范围；Web 功能目录前置四类用途索引、分组列表与键盘焦点；修复旧样式隐藏第四条最近记录 | 真实登录、四条笔记、320 px 与四类键盘跳转通过；发现原生刷新 / 重建的 UI 生命周期问题、Android 旧 Coding 上传入口与关闭按钮误译。 |
| 4 | 首页添加入口使用统一记录框，未登录页面说明添加→资料库→问答；记忆执行队列渐进展开且错误保持可见；修复原生状态刷新与功能菜单重建，清理旧 Coding 可见入口而保留旧路由 | 首屏层级改善；独立复评发现最近记录文字、Mac 链接对比度不足，Android 文件任务在只有地址、没有凭据时误称已连接。 |
| 5 | 修正文字对比度与文件目的地说明；修复 Android 320 dp 大字体标题、笔记详情关闭文案及无关媒体提示；清理已连接内容选择器中的旧 Coding 上传类型；完成实际语言切换、笔记阅读和完整核心旅程复查 | 选择第 5 轮：Web 原四项为 8 / 7.5 / 8.5 / 8.5，新增项 8.5；Mac、Android 为 8 / 6.5 / 8.5 / 8.5，新增项 8.5。原生原创性仍低于本项目校准目标 7，保留此缺口。 |

第五轮的选择依据是对比度、真实连接边界和阅读细节的改进，没有用新增指标覆盖原指标。完整结果、执行命令、合成预览和未验证边界见 [最终验证记录](../validation/ui-iterations-2026-10-13.md)。
