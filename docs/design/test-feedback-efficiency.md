# Bounded test feedback changes

Base: `20e28f8a6c1c066a546bb533e38086096da87ef2` (main). This plan covers only test tooling and contributor instructions. It does not change product behavior, CI activation, merge requirements or release gates.

- KEEP: every functional suite, assertion, input scale, 120-second file timeout, live/performance opt-ins, process-group cleanup, shared repository lock, explicit original-receipt reuse and conservative product-source invalidation.
- CHANGE: add explicit repeated `--file` selection to the Server launcher (replace the default collection, reject missing/empty/non-test selections). Add `check:affected --test-file <repository-relative Server test>` for focused execution under the existing driver/lock/receipt. The managed focused plan performs environment checks, builds shared/agent prerequisites and runs only selected tests; it is not a merge gate.
- CHANGE: partition the complete Server functional inventory into 16 stable filename-hash buckets. Each nonempty bucket is a separate driver task, using the same launcher. No files are omitted or duplicated. A top-level test-only correction invalidates its bucket; shared fixtures, product code, dependencies, tools and configuration still invalidate all relevant buckets. Cross-test imports must be treated conservatively: a bucket includes all other suite entries if any selected test imports another top-level suite (or reuse is disabled for that bucket).
- CHANGE: declare task prerequisites. Continue independent tasks after ordinary assertion/typecheck/build failures; skip dependents with explicit `unrun` reasons. Unknown external plans without dependencies retain fail-fast behavior. Environment failure blocks the plan; source mutation, signals and uncertain cleanup stop execution. A failing candidate remains failed.
- CHANGE: resolve Android SDK once through a shared helper, pass the resolved SDK to the actual Gradle child, and preflight Java 17+, platform 36/android.jar and build-tools before expensive work. Android plans prepare the shared/agent Node fixture prerequisites and probe Server native SQLite. No native build is required for this tooling PR.
- CHANGE: default Server worker count is clamped to 1..6 available CPUs, preserving explicit Node overrides.
- REMOVE: mandatory whole-Server reruns after isolated test corrections; first ordinary failure hiding independent failures; SDK discovery that is not consumed by Gradle.
- EXCEPTION: no inferred single-test product dependency graph; no automatic receipt discovery; raw native commands still require manual resource coordination. Focused receipts do not satisfy missing full-plan tasks.
- UNKNOWN: end-to-end speedup and platform/live behavior are unmeasured here. Report only focused generated-fixture results; no product long suite, device, UI, model or release run.

Validation: generated real CLI fixtures for file selection, invalid selection, one failure plus independent passes/dependent skips, prerequisite failures, unchanged-bucket receipt reuse, all-file inventory coverage, conservative source/helper invalidation and SDK handoff.
