## 当前旅程与视觉责任

沿用 [行动优先 ADR](../adr-client-action-first.md)、[客户端导航](../client-navigation.md) 和 [共同风格合同](ui-art-direction-five-rounds.md)。Web 的今天、资料库、问一问、活动、采集与设备以及原生端的首页、内容、问一问保持原责任。设置只服务配置、验证与维护；新记录在首页和内容任务入口可达。

共享冷灰背景、白内容面、单一蓝色强调、系统无衬线字体、线性图标、稳定控件边界和组内浅分隔贯穿各端。成功、警告与错误只用于真实状态；辅助说明使用中性色。打开添加选择器或前往另一任务使用次级描边，保存、开始、连接和发送等执行操作使用主动作。系统选择器、权限、底栏与原生返回保留平台交互。

审查范围包括首页、内容列表与完整原文、笔记、问答、来源与导入、模型与处理、连接、采集、隐私、存储、权限、更新、诊断和关于页。重点状态为加载、空内容、已有内容、运行、离线或缺少配置、失败、未保存草稿、长说明和长元数据。采用中英文常规与窄屏核心矩阵，并补充浏览器放大、桌面缩放、Android 大字体及 IME。

## 验收规则与本次调整

所有者先要求逐页实际看图、对照第五轮预案。该阶段按页面、二级设置、详情、弹窗及重要状态建账；中英文、常规与窄屏、缩放、大字体和输入法分别记录，长页覆盖中部、末端、展开项及内滚动。检查颜色、字体、图标、动作强调、边界、排版，以及完整限制、来源、时间、状态和返回位置。

随后所有者明确调整剩余工作：“剩下的都不要用视觉能力去查了，就是用 widget Test 之类的去测一下就 OK。快速做完，然后提 PR。”本次剩余验收采用控件、交互及自动化测试，不再继续逐图检查或为视觉补证扩展截图矩阵。

1. 第五轮仍是实现依据，保持已确认的信息架构、视觉角色和页面职责。
2. 已有视觉结论、原图 SHA-256、producer、构建身份、历史失败和修复对应关系保留。未查看的图片保持未查看；自动化通过不改写成视觉通过，旧图不重贴为新构建。
3. 剩余项使用真实控件和既有产品入口验证内容、数值、状态、可达性、保存、返回、草稿、错误与生命周期；运行受影响组件及消费者的必要检查。使用生成资料和隔离环境。
4. 已确认的功能失败需要修复并建立可行的回归验证。未完成的视觉覆盖另列边界，按所有者本次调整不继续作为提交 PR 的阻碍。
5. PR 明确区分实现、已有视觉检查、实际自动化验证及未验证范围；当前交付点为提交 PR，不把提审写成已合并或已发布。

代码、构建、DOM、尺寸断言与自动截图不能证明画面符合预案。单张首屏也不能证明整页；本次采用自动化验收剩余项，是所有者对验收方式的明确调整，不是全部页面已完成视觉检查的声明。生成场景通过不代表物理设备、真人理解或真实模型验收。

逐页复核还包含原生默认控件：Android 主题颜色通过同一 token 生成器的 XML 输出接入，Mac 计量条显式使用蓝色数据角色。来源规则的长选项沿用完整既有翻译，窄窗补充自然换行的当前选择说明。DEV 关于页沿用手动下载安装职责，隐藏该分支不提供的自动更新渠道和专用于自动更新的验签说明。

## Supersession

- **KEEP**：原信息架构、权限、采集与发送意图、处理范围、保留政策、原文、来源与时间、草稿保护和原任务返回。Android 阅读窗口关闭后重建保持关闭的回归保留。
- **CHANGE**：将第五轮公共视觉角色覆盖至此前遗留的设置、管理和状态组件；窄屏排版、长说明节奏及页脚空间按实际可见尺寸适配。
- **REMOVE**：无角色依据的暖色辅助表面、混用边框和圆角、遮住内容的固定页脚预留、描述已移除功能的过期存储文案，以及 DEV 手动下载分支中的自动更新专属说明。
- **EXCEPTION**：真实错误、限制、处理状态、采集范围和数据去向继续可见；原生系统界面不要求像素相同。完整说明可以通过具名展开项访问，原文不缩减。
- **EXCEPTION（验收方式）**：按所有者后续要求，未完成的视觉覆盖改用控件与自动化验证；既有失败、未查看项及验证边界仍如实记录。
- **UNKNOWN**：物理设备、真实个人采集、真实账号和模型、真人审美及完整无障碍认证，不能由生成 fixture 推断。

本次没有新增权限、保留、发送或处理政策，也不把布局分组用于语义分类。源码、构建、生成资料界面与发布身份分别核验，实际结果见 [落地验证](../validation/ui-rollout-2026-10-14.md)。
