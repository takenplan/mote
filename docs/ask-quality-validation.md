# 问一问：跨来源状态回顾回归方案

本文件定义宽时段状态回顾及同一对话内按月续问的生成回归方案。公开验证材料只包含生成原件、生成回执、通用机制和自动检查事实；语义判断必须依据对应试验的实际答案与原文，不能用提示合同测试代替。

相关契约见[对话与续问](conversations.md)、[检索与证据](agent.md#检索与证据)、[统一查询 ADR](adr-system-refactor.md)、[Memory 上下文读取](memory-context-reading-validation.md)、[新近度与进展表达](testing-archive-recency.md)和[系统改造质量判据](design/system-refactor-validation-2026-10-10.md#4-固定语义质量判据)。模型决定检索与解释；本方案不增加关键词意图分类、固定工具顺序、固定答案模板或新的用户模式。

## 失败模式与诊断边界

来源接收、转写就绪、当前 Material、已发布 Memory、未完成任务及模型实际读取是不同状态，必须分别核对。原件已就绪不能证明回答读到了相关段落；Memory 未完成也不能证明原件不可读。少量开场导航卡片、一次检索未命中或局部预览不能证明宽范围覆盖。引用数量和工具调用数量本身不是语义质量判据。

诊断还需区分数据表示、时间线索、检索策略和表达选择。重复的结构包装不能被解释为独立发言或重复行为；导入时间不能替代原文事件时间。真正容量失败、超时、参数拒绝和未读取的尾部各自保留明确状态，不能因字符或 token 观测值较大就推断某种失败已经发生。

## 生成资料与初始状态

回归使用隔离资料库、合成来源身份及全新生成正文。固定语义时钟、时区、组件版本、模型配置、语料 manifest 和散列；问题、事实定位及评价规则在试验前冻结。生成事实由模型理解，宿主仅按来源身份、时间元信息、授权、版本和执行状态准备输入。资料主题使用虚构的玩具制作、练习阶段和工具整理，不复制个人记录或据其改写情节。

| 输入或状态 | 必须包含的生成变体 |
| --- | --- |
| 多来源转写 | 多个合成录音来源的已就绪转写，经正常接入和 Material 整理入口归档；相关线索分布在不同来源和时间段中 |
| 其他归档输入 | 加入生成文档、笔记及无关资料；固定数量和长度分布，让关键证据不能只从最新一页取得 |
| 状态与变化 | 虚构练习的阶段性进展、玩具制作的开始与完成、尚无结果的工具整理计划，以及第三方引述 |
| 单次事件 | 一次尝试烘焙，只证明当日活动，不支持长期偏好、频率或生活习惯 |
| 长转写 | 关键变化和结果位于初始预览、首个材料页面及前部块之后；原文的时间框架和后部纠正需合并解释 |
| 段落结构与冗余 | 生成 `paragraph` 正文与 `sentenceList` 逐字重复的嵌套 JSON；保留真实重复段落作对照。结构中有源时间字段，但某些规范片段时间为空 |
| 日期线索 | `timeBasis=unknown` 且未填事件日期，但独立来源记录或正文具有明确时间框架；另有只有库内创建或导入时间、无法确定事件日期的对照 |
| Memory 混合状态 | 部分相关 Memory 通过正式提取、独立审核及发布入口生成，另有原件已就绪但任务未完成的资料。开场导航不足以独立回答问题 |
| 检索配置 | 明确记录 embedding 是否启用，字面检索保持可用；不同配置单独分组，不能把其中一组结果替代另一组 |

抓取或接收时间、库内创建时间、来源录制或开始时间、叙述事件时间分别核对；源结构字段不因存在于 JSON 就具有事件日期语义。录制时间不能无条件给叙述的历史事件定月。正文回顾框架、相对日期、跨年例外及更正需结合读过的上下文解释。详见[录音时间契约](recorder-connectors-design.md#厂商契约与证据保真)与[Memory 日期解释](adr-memory-context-reading.md#个人策略版本与解释)。

准备阶段核对来源接收、当前 Material、转写可读性和 Memory 任务状态，并在独立评价 manifest 中记录生成事实的精确原件范围。不能手工插入最终答案、直接构造内部 Memory 行或让模型看到评价 manifest。脚本模型可验证宿主传输及状态，其预设答案不能证明真实模型完成综合判断。

## 用户旅程

1. 启动隔离 Central，通过正常来源接入、文档导入确认或笔记入口送入生成输入，等待指定转写与 Material 就绪。保留部分 Memory 任务的未完成状态，确认原件仍可读。
2. 以所有者身份通过 `POST /api/query-runs` 发送开放的宽时段状态问题，显式传入固定时区；不预先要求工具、具体词语或答案栏目。记录返回的 `conversationId`、`turnId`、引用、工具及用量。
3. 使用同一 `conversationId` 通过 `POST /api/query-runs` 继续追问按月变化。前轮助手答案是可纠正的上下文，不能替代本轮重新查证。
4. 硬范围试验逐轮显式发送 `after` / `before` / `deviceId`，按[续问 API 契约](conversations.md#api)核对范围；省略这些字段不继承上轮过滤，省略 `timeZone` 才继承上轮时区。自然语言月份与硬范围试验分别保留。
5. 对照网页「问一问」的 `POST /api/query-runs` → 运行进度 → 已保存对话路径，通过 `GET /api/conversations/:id` 核对保存及刷新后的续问行为。

自动 API 与网页验证默认在后台执行。生成场景不采集或发送个人截图，不向查询模型开放来源配置修改、历史 Memory 重做或外部写入能力。

## 质量判据与高风险组合

按生成 manifest 中与问题相关的事实、变化、证据范围及时间约束审读，不按关键词命中、卡片数量、引用数量或固定文案判定。模型可直接检索或使用已有独立研究能力；读取应足以支持结论，无需遍历全库或逐份引用资料。

| ID | 组合及失败状态 | 预期行为与检查 |
| --- | --- | --- |
| AQ01 | 宽时段问题＋多来源就绪转写＋无关输入＋少量开场导航 | 综合分散的相关状态与变化；不把导航或孤立事实当作完整覆盖，也不把未读材料称为不存在 |
| AQ02 | 已发布 Memory＋就绪原件的任务未完成＋字面检索 | Memory 用于导航，原件用于补证；具体缺口保持限定，不归为全部未同步或未处理 |
| AQ03 | 首问完成＋同对话按月续问＋前轮遗漏或错误 | 重新核对月度差异和必要上下文，有证据时纠正遗漏；旧答案不是独立证据 |
| AQ04 | 日期元信息 unknown＋可信来源时间或正文框架＋未知日期对照 | 阅读能改变时间判断的原文及背景；区分录制、回顾、事件和导入时间，既不一概排除也不编造月份 |
| AQ05 | 一次烘焙尝试＋长期状态问题＋其他持续状态证据 | 事件保持当日范围，不升级为习惯；只说明影响所问结论的缺口，不附加无关频率或目的清单 |
| AQ06 | 长转写后部关键块＋较大工具结果＋Memory 未完成 | 请求页面按正常范围读取，返回 `nextOffset`；不因近似字符配额缩页。实际资源失败不能被包装为原目标完整 |
| AQ07 | 导入晚于发生＋跨年回顾＋后部更正 | 结论随实际框架和更正变化；不把导入月当发生月，也不把开头年份套给所有事件 |
| AQ08 | 混合说话人＋适用来源说明＋第三方引述 | 根据当前声明和上下文解释主体；不将第三方经历归给主人，也不将默认 unknown 机械当作相反证明 |
| AQ09 | 首问后新资料、处理产物、纠正或删除＋续问 | 续问使用当前允许的证据；旧引用、Memory 和对话不能恢复被撤销的权限 |
| AQ10 | 重复段落包装＋缺失片段时间＋后部关键块 | 交付可读正文及时间线索，结构重复不成为独立证据；精确引用仍核对原件、版本、偏移和授权范围 |
| AQ11 | 计划制作玩具底座＋主体已完成＋底座无开始证据 | 不以主体完成推断底座正在制作或已完成；未知后续结果保持未知 |
| AQ12 | 较早练习卡关＋已读的阶段通过记录＋后续阶段未完成 | 保留直接回答变化的已通过进展，同时限定后续未知；区分没读到与读后省略 |
| AQ13 | 工具整理已开始＋后续步骤是计划＋压缩后的月度续问 | 保留已经开始的事实，不能弱化为整理倾向，也不能把整个计划写成已完成 |

多来源、混合 Memory 状态、续问、时间线索和长文后部需在同一生成旅程中组合执行，不能只用两两覆盖替代。表示冗余同时覆盖日期解释和长文读取；其余语言、输入长度、时间可靠性、归属和生命周期按两两覆盖补充，并保留明确的语义反例。

评价分别记录相关事实覆盖、变化与时间判断、主体归属、事件和状态区分、引用支持、缺口准确性与自然表达。有依据的概括可以简洁；简洁不能抹去直接相关的已知进展，保守也不能掩盖未尝试读取的线索。

## 执行证据与当前状态

执行报告记录生成 manifest、组件版本、模型设置、时区和时钟、检索配置、请求范围、工具实际披露、引用和答案，以及可得用量。比较前等待确定性整理完成，冻结输入并核对各组共同指纹与运行前后指纹。问答失败与数据变动分别记录，不能相互遮蔽。

| 验证层级 | 可验证的合同 | 限制 |
| --- | --- | --- |
| 录音接入生成 fixture | 单份主正文、原始 JSON 留存、实际重复、来源时间、异常非空结构、重试与重启 | 不证明真实 ASR 或物理设备时间精度 |
| 正式 HTTP 与本地脚本模型 | 来源接入、问答保存、连续追问、Memory 激活和恢复 | 预设回答不证明语义综合或自然表达 |
| 大范围授权与实际传输入口 | 全量范围保留、租约续期、目录与正文撤权、外联和发布栅栏 | Codex 只能逐次检查可观察的 `turn/start`，不能声称观测其内部供应商请求 |
| Agent 提示及生成证据传输 | 各归档角色共用覆盖、自检和行动状态责任，原文不被宿主改写 | 提示字符串测试不是模型语义验证 |
| 生成语料的模型质量试验 | 根据固定事实、实际工具披露和答案人工核对覆盖及表达 | 一次成功不证明一般召回率、稳定性或性能因果 |
| 受影响组件检查 | 构建、类型、工具与生命周期回归 | 自动检查不等于部署、物理设备或真实模型质量验证 |

具体自动回归入口见[租约与启动授权验证](validation/query-lease-and-memory-activation-2026-10-14.md)、[Memory 范围评估](memory-range-evaluation-validation.md)及[新近度与进展表达](testing-archive-recency.md)。检查命令与受影响消费者范围遵循[开发协议](testing.md#early-integration-and-candidate-checks)。

各次语义试验保留代码、数据和模型边界，不把不同版本混为同版本横向对照。累计线程用量可能含重复输入和缓存；未知费用、请求次数和失败用量保持未知，不按零消耗补算。未知写请求先保留收据，再按精确输入与唯一任务核对，不能因超时自动重复付费工作。
