# 当前内容存储

当前生产为 Central epoch 5、Desktop / Android 本机格式 4。旧 owner 库、旧本机格式和旧密文包装不自动转换；同代正常更新无需清空，跨代先保留旧程序、目录和必要密钥，再选择新空 profile，见[更新说明](updating.md)。

## 客户端

| 内容 | Desktop | Android |
| --- | --- | --- |
| 截图、事件、来源正文和暂存原件 | 格式 4 原始字节，应用私有目录；无可选内容加密或旧密文 reader | 格式 4 原始字节，包含缩略图、队列索引、本机笔记草稿和待决定区 |
| Prod 凭据 / 恢复 | Electron safeStorage；session-only token 不持久保存 | Keystore SecretBox，保留原进程绑定会话及退出授权门禁 |
| Dev 凭据 / 恢复 | 私有 0600 JSON 配置与配对检查点，不调用 Keychain | token 为同一原子私有设置快照中的 JSON；SecretBox 的 AES 密钥在私有 JSON，中央私有草稿/ledger 仍认证加密，不访问 Keystore |
| Test 与第三方组件 | Test 隔离 fixture；第三方 CLI 凭据管理保持各自方式 | Test 保留系统保护及独立安装身份；不借 Dev 例外放宽 Prod |

文件按 Profile/账号作用域保存并排除支持导出。旧 Dev 系统加密状态明确拒绝，不自动转换；切换前保留旧数据，按[Profile 决策](adr-profile-release-policy.md)显式创建空 Dev 目录或重置 Dev 安装。未归档的本机内容在清除/卸载后可能丢失。队列备份/导入仍核对当前格式及账号归属，不用于跨账号迁移。

## 中央

原件加密是个人 `storage.contentEncryptionEnabled`，默认 false，保存于当前账号 ConfigService。每账号使用部署/账号散列原件目录和独立托管密钥/指纹；没有调用者可选的全局原件密钥。管理员身份不会通过普通个人 API 获得读取他人内容、密钥或配置的权限。部署者仍能接触服务器文件、托管密钥和处理中的明文；这不是端到端加密或对操作系统管理员的隔离。准确 HTTP 与生命周期见[个人内容存储合同](design/multiuser-content-storage.md)和[多用户威胁边界](adr-multiuser-scope.md)。

`.plain` / `.aes` 是当前对象表示，未来写入按策略选择；开关不改写旧字节。读取 `.aes` 必须有正确密钥，失败保留原文件。关闭未来加密后仍可显式发起 `storage.decrypt`：同一 M05 执行器负责准确 operation ID、进度、取消、逐片检查点和重启恢复。取消保留已转换文件，损坏/冲突对象不删除。原件仍有实际活动时等待，不假称旧 worker 已停止。

加密覆盖账号原件和上传片，不加密整个 SQLite、所有解析文本、索引或私人模型凭据。目录权限、磁盘保护、HTTPS、访问授权、散列校验与本机隐私过滤继续独立生效。密钥丢失不能靠重新登录或下载模型恢复密文。

## 备份与统计

当前完整实例备份包含恢复所需托管密钥、私人配置、规范数据库与原件，按整实例秘密保管。个人便携归档包含本人获准原件的明文，不携带密钥或可复用授权；导入按当前账号写入策略保存，限原部署/原账号。详见[部署备份](deployment.md#备份恢复和迁移)。

个人物理统计计入自己管理的原件、片、工作文件及固定私有目录，不把共享 SQLite、索引、模型或别人的文件分摊成虚构个人占用。实例逻辑容量账本是另一项准入责任。历史测量和验证保留原日期，不代表本次执行。
