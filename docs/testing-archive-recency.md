# 归档问答的新近度与阶段覆盖验证

宽期回顾需要比较相关的较早、较晚阶段。概括近期或当前状态前，模型应查找并阅读选定范围内最新的相关原文，判断它们延续、限定还是改变早期结论，并把支持的变化保留在最终回答中。某来源较早时段的检索未命中，不能覆盖该来源在请求期间的较晚时段。新近度按相关的原文发生、写作或记录时间判断；Memory 生成、发布时间不能替代原文时间，也不能把回忆中的旧事移到现在。

这项责任由 `task-context.ts` 的共享提示传入归档问答系统规则和上下文，普通回答、委派研究、表达与复核角色使用同一合同。模型继续选择相关来源、工具和阅读范围；没有新增关键词分发、固定工具顺序、每源枚举、时间阈值或全库阅读要求。较晚的一次事件也不能自动反转长期状态。受限证据提取、日程提取和工作记忆不新增归档发现义务，包含空种子或未知来源协议的回退路径。

综合与压缩时还需保持原文的行动状态和承诺程度：意向或计划、明确已开始或正在做、以及有依据的完成或结果。计划不能被写成已经着手；有明确依据的开始、通过或改善，也不能被弱化为倾向或意愿。保留直接回答用户状态或变化的有效进展，最终结果尚未知不能抹去已经发生的阶段进展。这属于既有模型自检责任，不由代码确定主题、指定必须出现的字段或预填答案。

## 生成场景矩阵

下列原文、日期、来源和角色关系全部使用全新生成数据，主题为虚构的玩具制作、练习阶段和工具整理。每例通过正式问答入口发起宽期回顾，再以同一会话追问近期状态；各质量策略保持相同数据指纹、宿主时间、模型设置和授权范围。

| 场景 | 资料与状态 | 验收依据 |
| --- | --- | --- |
| 旧 Memory 刚发布，较晚原文尚未生成 Memory | 较早原文记述一段困难；其 Memory 在当前日期发布。某来源较早时段的搜索为空，但请求期间的较晚原文已经就绪，记述相关进展；该原文的 Memory 仍未完成。 | 不按 Memory 发布时间认定最新状态，不因较早搜索为空放弃该来源的较晚期间。实际查证相关较晚原文；两轮回答区分早期情形与后续变化，引用本轮成功交付的原文。 |
| 较晚仅有一次具体事件 | 较早的多份原文支持一个阶段性模式；较晚原文只证明一次完成或体验，没有证明该模式已持续改变。 | 回答保留有证据的事件与阶段变化，避免把一次事件提升为新习惯，也不自动宣布长期模式消失。 |
| 较晚更新位于选定范围外 | 请求有明确时间或设备范围；更晚的相关记录位于范围外。范围内仍有可读的早期与较晚资料。 | 不扩展授权范围或引用范围外记录。回答以范围内证据描述变化；只有影响结论的缺口需要具体说明。 |
| 玩具底座仍是计划 | 生成原文说准备下一周给玩具制作底座；玩具主体已经组装好，没有底座的开始或完成记录。 | 区分主体完成与底座待办，不因前者完成就写成底座正在制作或已完成。语义结果需核对实际答案与原文，单纯找到相关记录不能算通过。 |
| 已读的练习阶段进展被省略 | 较早生成原文说一个练习阶段尚未通过，较晚原文明确该阶段已经通过；后续阶段仍未完成。工具 trace 需证明较晚段落实际交付。 | 保留直接相关的阶段通过进展，同时限定后续未知；不能只重复练习仍在继续，也不能说整个练习已完成。结合 trace 区分未读与读后省略。 |
| 工具整理已开始却被弱化为倾向 | 生成原文明确已将第一盒工具分类，余下几盒仍计划整理。第二轮按时间段压缩同一组记录。 | 保留已经开始的有效进展，把后续计划单独表达；不能压缩成整理倾向，也不能说所有工具已整理完。前轮答案仍需当前授权原文验证。 |

## 验证层次

`packages/agent/test/instructions.test.mjs` 与 `task-context.test.mjs` 检查共享责任在各归档角色、两种原生工具模式中的传递，保持选定范围和原始 Memory 日期，并确认受限或工作任务没有新增发现义务。计划、阶段进展和项目开始的生成原文保持原样交付，宿主不改写语义、注入预期答案或要求进展字段。已有引用与权限消费者继续检查未读原文不能引用、当前声明及选定范围不能被提示覆盖。

这些确定性测试验证提示和权限合同，不能证明真实模型一定选择充分的资料或写出完整概括。生成矩阵的语义结果需要另外审读实际检索 trace 与最终回答，并与固定数据、固定模型设置下的补丁试验对照。修补前的多策略结果保留其原代码版本；修补后的单策略试验单独记录版本、用量、耗时和遗漏，不能混称为同版本对照。测试和真实模型结果均按实际执行状态报告。


每个提示修补使用独立的生成试验记录，保留修补前后的代码、输入指纹、模型设置、实际披露和语义判断。没有陈述某项计划，只能说明该答案没有出现相应措辞错误，不能算正确区分计划与行动的正向验证。一次试验也不能证明一般召回率、稳定性或因果提速。验证状态按实际执行记录，不从提示存在或预设回执推断通过。
