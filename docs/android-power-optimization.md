本文保留按 2026-09-16 的 [架构对比讨论](https://chatgpt.com/share/6aaa0c78-a5e0-83e8-b965-3e5ca92b2f00) 实现非 Qwen 推理侧的优化。没有修改 Qwen 模型、提示、推理参数、进程重载、JNI 输入协议或后端，也没有替换隐私模型。

## 采集处理

- 已开启图片去重时，在原始帧上先做变化检测。只有已成功保存的新帧能成为比较基准；应用及全部可见窗口身份、分辨率或任意配置变化会使基准失效。暂停会清除基准。
- 命中后丢弃当前图片，保留独立的 `activity` 记录及实际采样时间，不包含图片、OCR、标题或“审查通过”结论。近似去重可能漏掉细小变化，不能作为安全审查结果缓存。
- 新图片继续走原有隐私审查、遮罩、OCR 和持久化流程；失败仍关闭。去重关闭时仍处理每帧。已有用户的档位不自动修改。
- 图片对比诊断需要保存已审查、已遮罩的图片对，因此开启它时保留后置去重路径，暂不进行早期跳帧。诊断是按需功能，不用于日常省电。
- 无障碍与投屏的全尺寸软件像素复制移到工作线程，交回时再次验证窗口、配置、服务状态；比较像素数组按尺寸复用。原生模型的 PNG/共享内存协议保持不变。

## OCR 与默认范围

默认一次中文识别器调用；它同时支持中文和拉丁文，见 [ML Kit 官方说明](https://developers.google.com/android/reference/com/google/mlkit/vision/text/chinese/ChineseTextRecognizerOptions)。设置页可选拉丁文、双引擎，并通过包名映射为指定应用覆盖。选择依据是用户配置，不按文本关键词或语言猜测分流。识别器按需初始化，只用于用户配置的隐私文字规则；遮罩后的再次识别仍保留。旧充电补 OCR 队列已退役，归档正文的 OCR 在中央独立处理。

新安装默认只记录应用活动，用户在应用规则中明确开启内容采集。本机格式 4 要求完整的当前配置，不读取或补写旧内容默认值。所有可见辅助窗口仍遵守原有隐私规则。

## 调度与通知

配置读取返回不可变内存快照，只检查配置键的变化；运行状态写入不会重新解析配置或解密令牌。凭据按当前 Profile 的保护方式独立缓存，直接偏好变更和设置保存都会在下一次读取反映出来。Dev 使用私有文件，Prod / Test 保留系统保护，见[凭据政策](adr-profile-release-policy.md)。

通知按最终可见文本去重，重复状态不再重新发布，停止后只取消一次；旧通知清理只发生在初始化阶段。无障碍服务按下次采样截止时间安排任务，灭屏/锁屏或停止后不再持续轮询；亮屏解锁、重新开启及配置恢复会重新安排。同步独立于采集计时器运行。

## 同步协议

空队列（没有待传记录或来源更新）不再派发实时或定时上传任务。自动恢复任务在初始化或同步配置变化时注册；不注册旧充电 OCR 恢复任务。

设备心跳使用独立的 15 分钟恢复任务，遵守 Wi-Fi、充电及低电量限制；手动同步模式不自动发送。采集状态改变可安排一次心跳，相邻状态报告至少间隔一分钟；正常上传会更新中央的最后联系时间。上传任务不再发送开始与结束两次心跳，只尝试低频的结束报告。心跳失败不会撤销已确认的数据上传。中央状态是上次观察，系统休眠可能推迟报告；网页显示“状态待更新”不代表设备停止本机采集。

当前压缩采集将每条记录序列化为 JSONL，再 gzip 发送至来源限定的 `POST /api/ingress/sources/:id/captures`（`application/x-ndjson+gzip`），并携带准确 batch ID、Wire 2 与 Ingress 3 头。包及结构限制见[当前协议](protocol.md)，不沿用旧 bundle 端点的限制说明。图片和无图片观察可共享一次请求，实际成批时机仍由客户端同步设置决定。客户端保留本机权威副本，核对完整部署/账号/来源/批次及成员接收凭据后才清理。

客户端按当前配置选择编码与成批方式，均使用来源限定的 Ingress 3 路由；不因缺失路由回退旧协议。HTTP 200 本身不代替完整回执校验，也不证明中央处理、索引或 Memory 完成。

客户端先验证完整接收凭据，遗漏、异常或失败的记录保留。409 冲突和 410 墓碑按原规则隔离，不重新创建。404/405 表示当前接口缺失并保留失败，不协商旧端点；401/403/429 同样不降级。413 缩小批次重试，单条仍超限保留失败条目，详见[当前上传调度](upload-scheduling.md)。断连后保留原 ID、字节和批次身份，沿用原有幂等语义。

## 观测与验收

按需启用数值诊断后，可以导出截图请求、收到帧数、提前丢弃数、模型调用、实际 OCR 引擎调用、HTTP 请求、上传会话、心跳及通知次数；记录主进程 CPU 时间，以及推理、OCR、整帧、编码、入队、HTTP 的最近/累计/最大耗时与样本数。不记录正文、图像、令牌、包名或隐私判定内容。HTTP 统计覆盖 `HttpJson` 请求，不等同于进程全部网络流量。

自动测试只使用生成图片和合成数据，不读取个人截图，不调用真实模型。模拟器证明功能和调用数量，不能给出真机功耗百分比。真机亮度、刷新率、网络、温度及使用场景应固定，分别重复测量静态阅读、持续滚动和息屏待机；整机电量变化不能直接归因于单个应用。

本轮开发版测试 APK 跳过了未修改的 Qwen 原生库构建，仅用于非模型合成回归，不作为完整发行包。Qwen 相关的替代分类器、输出缩短、硬件后端、失败熔断、真实重载计数和直接像素传输按要求延期。
