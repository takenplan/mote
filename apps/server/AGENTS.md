# Central server

- Own HTTP/MCP, evidence, processing, Memory, Ask and Actions for one instance owner. Do not introduce an account host.
- Focused command (module directory unless noted): `node --import tsx --test --test-concurrency=4 --test-timeout=120000 test/connections.test.ts`. Select an existing affected file/class.
- Build shared/Agent inputs once when changed. SQLite must match the active Node ABI. `npm test` always uses the full test glob; appended filenames do not narrow it. Preserve cancellation, cleanup, late publication, deletion and restart coverage.
- Types for TypeScript modules: `npm run typecheck -w @mote/server`. Coordinate shared builds; do not rebuild shared output concurrently.
- Translate new `moteText` keys and synchronize Android English strings.
- Work in small modules, check changed behavior, and connect the real consumer early. The integration owner completes final affected checks after convergence.
- See [testing](../../docs/testing.md). Separate fixture, physical-device and live-model evidence.
